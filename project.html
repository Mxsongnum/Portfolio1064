Description : ในวิชา DMT221 GRAPHIC PROGRAMMING FOR DIGITAL MEDIAได้ทำโปรเจกต์เกมที่ทำงานร่วมกันกับขยะเพื่อรณรงค์การแยกขยะและลดปัญหาขยะล้นทะเล ผู้เล่นจะได้เรียนรู้ผ่านเกมเพลย์ว่า การทิ้งขยะถูกถังในโลกจริงจะส่งผลลัพธ์ยังไงบ้าง และเราจะช่วยกอบกู้ท้องทะเลได้อย่างไรผ่านเกม โดยระบบซอฟต์แวร์พัฒนาด้วย Processing และรับค่าเซ็นเซอร์จากถังขยะจริงผ่าน ESP32

หน้าที่รับผิดชอบ : ในโปรเจกต์นี้หนูรับผิดชอบในการออกแบบและทำระบบ UI ของตัวเกมโดยดูแลทั้งในส่วนของการทำกราฟิกและการเขียนLogicควบคุมระบบเมนู ที่จะมี ระบบการเลือกตัวละคร, และระบบการเข้า-ออกเกม

Tools Used: Processing, Arduino IDE
